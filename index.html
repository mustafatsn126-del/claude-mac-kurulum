TC 00:00 · HAZIRLIK

Başlamadan önce 5 kontrol

Bunlar hazırsa kurulum takılmadan biter. Hepsi 2 dakikada kontrol edilir.

✓

macOS 13 (Ventura) veya daha yeni. Ekranın sol üstündeki Apple menüsü → Bu Mac Hakkında. Açılan pencerede “macOS Sonoma 14…” gibi bir ad ve sayı yazar. 13 ve üstüyse tamam.

✓

Mac açılış şifren. Bilgisayarı açarken yazdığın şifre. Kurulumda bir kez sorulur.

✓

Yönetici hesabı. Mac'i kendi hesabınla kurduysan zaten yöneticisin. Emin değilsen: Sistem Ayarları → Kullanıcılar ve Gruplar, adının altında “Yönetici” yazar.

✓

En az 10 GB boş yer. Bu Mac Hakkında → Diğer Bilgiler (veya Sistem Ayarları → Genel → Saklama Alanı).

✓

Şarj kablosu takılı, internet açık. Ev Wi-Fi'ı yeterli. Kurulum sırasında kapağı kapatma.

Bilgisayar kapanmaz, yeniden başlamaz

Kurulum boyunca Mac yeniden başlatılmaz. Komut, ekranın uykuya geçmesini de kendisi engeller; bitince bu engel kalkar.

YOL A · ÖNERİLEN

Tek yapıştırmayla her şeyi kur

Terminal, Mac'e yazıyla komut verdiğin bir penceredir. Korkulacak bir şey yok: aşağıdaki komutu kopyalayıp oraya yapıştıracaksın, Mac de listedeki her şeyi sırayla indirip kuracak.

1

Terminal'i aç

Klavyede ⌘ Command tuşunu basılı tut ve Boşluk çubuğuna bas. Ekranın ortasında bir arama çubuğu (Spotlight) açılır. Terminal yaz ve ↩ Enter bas.

Siyah veya beyaz bir pencere açılır. En altta adın ve % işareti görünür. Bu, Mac'in komut beklediği anlamına gelir.

2

Komutu kopyala

Aşağıdaki kırmızı çerçeveli kutunun sağ üstündeki Kopyala düğmesine bas. Kutunun içindeki her şey tek seferde kopyalanır. İçindeki yazıları okumana veya seçmene gerek yok.

cat > ~/zeynep-kurulum.sh <<'KURULUM'
#!/bin/bash
# Zeynep icin: Claude masaustu + Claude Code + foto/video araclari (macOS 13+)
set -u

R=$'\033[0m'; B=$'\033[1m'; KIR=$'\033[1;31m'; YES=$'\033[1;32m'; SAR=$'\033[1;33m'; MOR=$'\033[1;35m'
adim()  { printf '\n%s━━━ %s ━━━%s\n' "$MOR" "$1" "$R"; }
tamam() { printf '%s✔ %s%s\n' "$YES" "$1" "$R"; }
uyari() { printf '%s! %s%s\n' "$SAR" "$1" "$R"; }
dur()   { printf '\n%s✖ %s%s\n\n' "$KIR" "$1" "$R"; exit 1; }

printf '\n%sMerhaba Zeynep! Kurulum başlıyor.%s\n' "$B" "$R"
printf 'Toplam 15-40 dakika sürebilir. Bu pencereyi kapatma, Mac şarjda kalsın.\n'

[ "$(uname -s)" = "Darwin" ] || dur "Bu kurulum yalnızca Mac içindir."
SURUM=$(sw_vers -productVersion)
ANA=${SURUM%%.*}
[ "$ANA" -ge 13 ] || dur "macOS $SURUM eski. En az macOS 13 gerekiyor: Apple menüsü > Sistem Ayarları > Genel > Yazılım Güncelleme."
tamam "macOS $SURUM uygun"
groups | grep -qw admin || dur "Bu Mac hesabı yönetici (Admin) değil. Yönetici hesabıyla giriş yapıp tekrar dene."

# Kurulum surerken Mac uykuya dalmasin; betik bitince kendiliginden durur.
caffeinate -dimsu -w $$ &

adim "1/6 Mac şifresi"
printf 'Mac açılış şifreni yaz ve Enter (↩) tuşuna bas.\n'
printf 'Yazarken ekranda HİÇBİR ŞEY görünmez; bu normal, yazmaya devam et.\n'
sudo -v || dur "Şifre kabul edilmedi. Komutu yeniden yapıştırıp tekrar dene."
# Uzun adimlarda sifrenin tekrar sorulmamasi icin oturumu canli tutar.
( while true; do sudo -n true; sleep 50; kill -0 $$ 2>/dev/null || exit; done ) 2>/dev/null &
tamam "Şifre alındı"

adim "2/6 Homebrew (program yükleyici) + Apple geliştirici araçları"
if [ -x /opt/homebrew/bin/brew ]; then
  BREW=/opt/homebrew/bin/brew
elif [ -x /usr/local/bin/brew ]; then
  BREW=/usr/local/bin/brew
else
  printf 'İndiriliyor: Apple Komut Satırı Araçları + Homebrew (yaklaşık 1-2 GB).\n'
  printf 'En uzun adım budur (5-20 dk). Yazılar akarken bekle.\n'
  NONINTERACTIVE=1 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" \
    || dur "Homebrew kurulamadı. İnternet bağlantını kontrol edip komutu yeniden yapıştır."
  if [ -x /opt/homebrew/bin/brew ]; then BREW=/opt/homebrew/bin/brew; else BREW=/usr/local/bin/brew; fi
fi
[ -x "$BREW" ] || dur "Homebrew bulunamadı."
eval "$("$BREW" shellenv)"
grep -qs "brew shellenv" "$HOME/.zprofile" || printf '\neval "$(%s shellenv)"\n' "$BREW" >> "$HOME/.zprofile"
tamam "Homebrew hazır"

adim "3/6 Claude masaüstü uygulaması"
if [ -d "/Applications/Claude.app" ]; then
  tamam "Claude zaten kurulu, bu adım atlandı"
else
  printf 'İndiriliyor: Claude uygulaması (birkaç yüz MB).\n'
  brew install --cask claude || dur "Claude uygulaması kurulamadı. Komutu yeniden yapıştır."
  tamam "Claude, Uygulamalar klasörüne kuruldu"
fi

adim "4/6 Claude Code (terminal sürümü)"
if command -v claude >/dev/null 2>&1 || [ -x "$HOME/.local/bin/claude" ]; then
  tamam "Claude Code zaten kurulu"
else
  curl -fsSL https://claude.ai/install.sh | bash \
    && tamam "Claude Code kuruldu" \
    || uyari "Terminal sürümü kurulamadı; masaüstü uygulaması yine de çalışır."
fi
grep -qs '.local/bin' "$HOME/.zshrc" || printf '\nexport PATH="$HOME/.local/bin:$PATH"\n' >> "$HOME/.zshrc"

adim "5/6 Fotoğraf ve video araçları"
printf 'İndiriliyor: Git, ffmpeg (video), ImageMagick (fotoğraf), ExifTool (fotoğraf bilgileri).\n'
for P in git ffmpeg imagemagick exiftool; do
  if brew list --formula "$P" >/dev/null 2>&1; then
    tamam "$P zaten var"
  elif brew install "$P"; then
    tamam "$P kuruldu"
  else
    uyari "$P kurulamadı. Sonra Claude'a \"$P aracını kur\" diyebilirsin."
  fi
done

adim "6/6 Çalışma klasörü ve Claude'a tanıtım notu"
mkdir -p "$HOME/Claude Calisma/Gelen" "$HOME/Claude Calisma/Cikti" "$HOME/.claude"
if [ ! -f "$HOME/.claude/CLAUDE.md" ]; then
cat > "$HOME/.claude/CLAUDE.md" <<'NOT'

- Adım Zeynep. Fotoğrafçı ve video editörüyüm; yazılım bilmiyorum.
- Benimle her zaman Türkçe, sade ve adım adım konuş. Teknik bir terim kullanırsan bir cümleyle açıkla.

# Dosyalarımla çalışırken

- Bir şeyi silmen veya taşıman gerekiyorsa önce bana sor.
- Büyük bir işe başlamadan önce 2-3 örnek dosyada dene, sonucu göster, onay verince hepsini yap.
- İş bitince kısa bir özet ver: kaç dosya işlendi, nereye kaydedildi.

# Araçlarım
- Mac'te kurulu: ffmpeg, ImageMagick, ExifTool, Git (Homebrew ile).
- Eksik bir araç gerekirse hangisini neden kuracağını söyle, sonra kur.
NOT
  tamam "Claude'a tanıtım notu yazıldı (~/.claude/CLAUDE.md)"
else
  uyari "~/.claude/CLAUDE.md zaten vardı, dokunulmadı"
fi

printf '\n%s✔ KURULUM BİTTİ, ZEYNEP!%s\n\n' "$YES" "$R"
printf 'Şimdi açılacak:\n'
printf '  • "Claude Calisma" klasörü (dosyalarını buraya koyabilirsin)\n'
printf '  • Claude uygulaması (hesabınla giriş yap)\n\n'
printf 'Bu Terminal penceresini artık kapatabilirsin.\n\n'
rm -f "$HOME/zeynep-kurulum.sh"
open "$HOME/Claude Calisma"
open -a Claude
KURULUM

YOL B · ELLE KURULUM

Claude'u kendin indirip kur

Terminal kullanmadan uygulamayı kurmak istersen bu yol. Uygulama kendi başına çalışır; ama videoları ve toplu fotoğraf işlerini yapabilmesi için sonda yine de 1 komut yapıştırman gerekir (adım 5).

1

İndirme sayfasını aç

Safari veya Chrome'da: claude.com/download. macOS için indirme düğmesine bas. Doğrudan indirme bağlantısı da şu: Claude for Mac (.dmg). Aynı dosya hem Apple Silicon (M1–M5) hem Intel Mac'lerde çalışır.

2

İndirilen dosyayı aç ve Uygulamalar'a sürükle

Dosya İndirilenler (Downloads) klasörüne iner: Claude.dmg. Dock'un sağındaki indirilenler simgesinden veya Finder → İndirilenler'den çift tıkla. Açılan pencerede Claude simgesini fareyle tut ve yanındaki Applications klasörünün üstüne bırak.

Sonra Finder'ın sol kenarındaki Claude diskinin yanındaki ⏏ simgesine basıp çıkarabilirsin; Claude.dmg dosyasını çöpe atabilirsin.

3

Claude'u aç

⌘ + Boşluk → Claude yaz → ↩. Ya da Finder → Uygulamalar → Claude. İlk açılışta “internetten indirilmiş bir uygulama” sorusu gelir: Aç'a bas. İstersen Dock'taki simgeye sağ tıklayıp Seçenekler → Dock'ta Tut diyerek sabitle.

4

Giriş yap

Hesabını açarken kullandığın yöntemle giriş yap (Google, Apple veya e-posta). Tarayıcı açılıp onay isteyebilir; onayla, uygulamaya geri dön.

5

Foto/video araçlarını ekle (tek komut)

Claude'un videoları dönüştürmesi, toplu fotoğraf işlemesi için Mac'te ffmpeg, ImageMagick ve ExifTool olmalı. Bunları kurmak Mac şifreni ister; şifreyi Claude yazamaz, o yüzden bu kısmı Terminal'den sen başlatırsın. Yol A'daki adım 1–5'i aynen yap ve aynı komutu yapıştır. Claude zaten kurulu olduğu için komut o adımı kendiliğinden atlar, yalnız eksikleri kurar.

Aynı kurulum komutu. Bu düğme Yol A'daki kutunun içeriğini kopyalar.

TC 00:40 · İLK AÇILIŞ

Claude'u ilk kez kullanmak

Uygulamanın üstünde üç sekme var. Dosyalarınla çalışmak için Code sekmesini kullanacaksın. Adı “kod” ama senin için yaptığı şey dosya işi: Claude, Mac'indeki araçları senin yerine çalıştırır.

Chat

Sohbet. Soru sor, metin yazdır, bir fotoğraf yükleyip yorum iste. Dosyalarına dokunmaz.

Cowork

Uzun, belge ağırlıklı işler ve telefondan Mac'e iş verme (Dispatch). Pro planda açılır.

Code

Asıl iş burada. Bir klasör seçersin, Claude o klasördeki fotoğraf ve videolarla çalışır: dönüştürür, adlandırır, sıkıştırır, altyazı çıkarır.

1

Code sekmesini aç, klasör seç

Üstten Code sekmesine tıkla. Yazı kutusunun altındaki ilk düğme Local olsun (“Mac'imde çalış” demek). Yanındaki klasör düğmesine bas ve ana klasöründeki Claude Calisma klasörünü seç. Fotoğraf ve videolarını önce bu klasörün içindeki Gelen'e kopyala.

Claude Calisma klasörünü nerede bulurum?

Finder'ı aç, üst menüden Git → Ana Klasör (kısayol ⇧ Shift + ⌘ + H). Klasörü Finder'ın sol kenarına sürüklersen hep orada durur. Bilerek Masaüstü yerine burada: Masaüstü iCloud'a eşitleniyorsa büyük video dosyaları internet kotanı ve iCloud alanını doldurabilir.

2

İzin modunu “Manual” bırak

Yazı kutusunun altındaki mod düğmesi başlangıçta Manual olsun. Bu modda Claude her dosya değişikliğinden ve her komuttan önce sana sorar; sen Allow / İzin ver dersin. Alıştıkça Accept edits moduna geçebilirsin; o zaman daha az sorar. Bypass permissions modunu açma.

3

Mac'in soracağı izinler

Claude bir klasöre ilk kez eriştiğinde Mac sorar: “Claude, ‘Masaüstü’ / ‘İndirilenler’ / ‘çıkarılabilir birim’ klasöründeki dosyalara erişmek istiyor.” İzin Ver'e bas. Harici SSD veya kart okuyucu kullanıyorsan “çıkarılabilir birimler” iznini de ver; yoksa Claude diskteki dosyaları göremez.

4

İlk denemen

Gelen klasörüne 5–10 fotoğraf kopyala, sonra bu cümleyi kopyalayıp Claude'un yazı kutusuna yapıştır ve ↩ bas. Türkçe yazman yeterli; Claude Türkçe cevap verir.

“Merhaba! Gelen klasöründeki fotoğrafları listele: her birinin çekim tarihi, kamerası ve boyutu ne? Hiçbir dosyayı değiştirme.”

Claude bir komut çalıştırmak istediğinde ekranda gösterir ve izin ister. Ne yapacağını Türkçe açıklar. Anlamadığın bir şey olursa “bunu daha basit anlat” yazman yeterli.

Yaptığı şey, o programlardan önce ve sonra gelen saatlerce süren tekrar işlerini üstlenmek: adlandırma, ayıklama, dönüştürme, boyutlandırma, sıkıştırma, altyazı, teslim. Sen Türkçe bir cümle yazarsın; Claude Mac'indeki ffmpeg, ImageMagick ve ExifTool'u senin yerine çalıştırır. Aşağıdaki cümlelerin hepsini kopyalayıp Code sekmesine yapıştırabilirsin.

Kullandığın programlarla birlikte

Lightroom · Photoshop · Premiere · Final Cut · DaVinci

Claude bu programların içine girip senin yerine fırça sürmez. Onların okuyabildiği dosyaları hazırlar ve onlara iş yaptıran betikler yazar.

Lightroom

Anahtar kelime, yıldız, telif gibi bilgileri dosyalara yazar. Lightroom'da Meta Veri → Meta Veriyi Dosyalardan Oku ile içeri alırsın. Dışa aktardığın klasörleri sonradan toplu işler.

Photoshop

Tekrarlanan işler için betik (.jsx) yazar. Photoshop'ta Dosya → Komut Dosyaları → Gözat ile çalıştırırsın: toplu boyut, katman adlandırma, şablona yerleştirme.

Premiere · Final Cut · DaVinci Resolve

Altyazı (SRT), proxy, ses eşitleme, format dönüştürme, kare çıkarma. SRT dosyasını üç programa da doğrudan aktarabilirsin.

Ekranında tıklama (Computer use)

Claude, izin verirsen ekranını görüp programlarda kendisi tıklayabilir. Bu özellik hâlâ deneme aşamasında, yavaştır, macOS 14 ister. Toplu işlerde komut yolu daha hızlı ve güvenilirdir.

Bilmen gereken sınırlar
  • Yaratıcı göz senin. Renk, kurgu ritmi, hikâye senin kararın. Claude teknik işi yapar, beğeniyi sen belirlersin.
  • Hata yapabilir. Bu yüzden tanıtım notunda “önce 2–3 dosyada dene, onay al” yazıyor. Sonucu görmeden 1000 dosyaya uygulatma.
  • Orijinallerin yedeği. Önemli çekimlerin bir kopyası her zaman harici diskte olsun. Claude'a orijinal klasörü değil, kopyasını ver.
  • Gizlilik. Claude'dan bir fotoğrafa “bakmasını” istersen o görüntü işlenmek için Anthropic'e gider. Toplu dönüştürme gibi komut işlerinde dosyalar Mac'inde kalır; Claude'a yalnızca dosya adları ve komut sonuçları gider. Müşterinin özel fotoğraflarında buna dikkat et.
  • Kullanım sınırı. Pro planda belli bir kullanım sınırı var. Dolarsa birkaç saat içinde yenilenir; çok yoğun kullanırsan Max'e geçilir.
